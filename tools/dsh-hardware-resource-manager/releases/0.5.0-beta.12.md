# DSH 硬件资源管理器 0.5.0-beta.12

在单处理器组 Windows 主机上，全机 CPU、物理内存或提交内存的最新实测占用任一达到 95% 时，暂停发放新的硬件和 PTC 主程序席位。等待请求继续入队，已获准任务继续运行，CPU 降额与工作集回收照常。三项低于 95% 后，调度器再检查席位和适用的内存余量，并按 FIFO 恢复准入。

## 安装包

[dsh-hardware-resource-manager-0.5.0-beta.12.tgz](./dsh-hardware-resource-manager-0.5.0-beta.12.tgz) 包含插件源码及 DSH Ops 0.5.5 接入补丁。按[安装说明](../README.md#安装)启用。

SHA-256 `9b9fa39ba00c95e21524de38d6872cfba85e929174e036b3c993c145d351b8f9`

## 验证

- Windows 原生回归 12 项通过，覆盖 95% 阈值、排队、回落恢复、FIFO、并发 CPU 降额和工作集回收。
- 在隔离的 DSH 配置中同时提交 36 项 PTC 请求。主程序并发上限为 4，32 个逻辑代理和 32 次原生工具调用完成，3 项在等待阶段取消。
- 上述 PTC 压测的工具席位为 256 MiB，宿主未配置外层内存上限。配置 768 MiB 外层上限的组合用例在 90 秒内未完成。
