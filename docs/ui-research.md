观察日期：2026-11-14（Asia/Shanghai）。应用：Aspen Plus V15，文件版本 41.0.0.614，中文界面。观察会话标题为 `Simulation 2 - Aspen Plus V15 - aspenONE`。来源是本机可见窗口和 Windows 辅助功能树，不是厂商源码、安装包反编译或文档中的假设。

## 研究边界

用户限定只做按钮及点击展开的菜单，不实现菜单项背后的功能；本轮不做二次验证，后续由 Mac 上的 Codex 编译验证。

采集期间仅切换功能区、打开文件侧栏、展开菜单并收起；没有选择会修改模型、单位、布局配置或文件的末级命令。结束时回到本次采集开始时可见的“文件 → 新建”页面。没有启动其他 Aspen 产品。

## 功能区覆盖

`ui/aspen-plus.json` 记录本次看到的文字、分组和菜单。主页的按钮名称同时有辅助功能树支持；查看、用户定义、资源主要从截图读出。

- 主页：剪贴板、单位、导航、工具、数据源、运行模式、运行、摘要、分析。
- 查看：缩放、显示帮助、显示、工艺流程视图、布局、窗口。
- 用户定义：设置、模型库、物性组、自定义模型。
- 资源：新增功能、示例、Aspen Knowledge、Aspen eLearning、支持中心、aspenONE更新代理、实时会话、发送至支持、帮助、关于。

## 已知差异与未覆盖项

- 辅助功能树有时为空，或在截图已切换标签后仍显示主页控件。实现以实际可见截图为准，未把返回的整棵树自动当成当前视图。
- 上一轮发现“查找化合物”弹窗的文字输入无法可靠送达；本轮未实现、未再验证该对话框。
- 原界面的禁用状态与案例数据有关；本外壳使用空案例下观察到的静态状态，不代表产品的完整权限或可用性。
- 无字图标的解释性名称包括“运行选项”“窗口列表”“窗口工具”及窗口前进/后退；最后一个窗口工具未确认功能，保留为无操作按钮。
- 文档区“所有选项卡”、导航折叠/底部选项及功能区收起入口只保留按钮；未采集的弹出内容不复用其他位置的菜单。
- `unexpanded: true` 表示看到入口但没有打开其内容。对齐、工艺流程视图的撤消/删除、布局切换等灰显入口没有伪造下一级菜单。
- 文件中的打开、另存为、导入、导出、修复文件、打印未展开其面板；选项、关于、帮助等对话框也未实现。
- 组分页的石油、非常规、SQL 服务器数据库、注释只记录标签；外壳暂禁用这些页签以免暗示已有对应内容。原软件并非全部禁用。
- 文件新建页只保留已见的类别和英制模板文字作为参照；不实现模板内容加载、单位切换和模板详情。
- 主页外其他功能区中的按钮尺寸、间距、图标是跨平台近似；没有承诺逐像素一致。Qt 图标与自行绘制符号代替原产品图标。
- 未覆盖模拟、安全分析、能量分析工作区；当前仅保留这些入口文字。没有穷举 Aspen Plus 的上下文菜单、所有子菜单或所有页面。
