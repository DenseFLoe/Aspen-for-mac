# 数据库界面与键鼠交互整改

日期：2026-11-15。依据用户实测反馈：整体布局可用、项目导出可重新打开、数据库查询可用；数据库相关页面和流程图交互仍与原版不同。本轮从已整合的 `main@73728c5` 建立 `codex/interaction-parity`，延续阶段 0–2，优先整改交互，不将后续计算阶段标为完成。

## 原版实测依据

本机 Aspen Plus V15 中文界面，`Simulation 1`，已有三个 Mixer、连接流股和独立流股。本轮通过 computer-use 实际观察以下路径；原有查找与组分页静态截图见 `docs/reference/find-compound.png` 和 `docs/components-research.md`。

| 操作 | 原版观察 | 整改目标 |
| --- | --- | --- |
| 设备右键 | 选中设备并显示菜单；输入、结果、流股结果、调和、更改工段、移动选择、禁用、转换成、成本、剪切、复制、重命名模块、旋转图标、交换图标、隐藏。无结果时相关项灰显 | 补上下文菜单、按对象启用、保留选择；已有编辑能力从菜单可达 |
| 流股线右键 | 显示选中控制点与流股菜单；输入、结果、调和、分析、更改流股类型、禁用、打断流股、插入模块、剪切、复制、重命名流股、重新连接、对齐模块、重排流股、隐藏、流股颜色和样式 | 流股与标签可命中，不把设备菜单误用于流股 |
| 空白处右键 | 放大、缩小、缩放到适当大小、隐藏标签、中心视图、平移、流程视图、重画、全选、分页预览、重置分页符、查找对象、粘贴、打印预览 | 提供画布菜单并接入已有缩放、选择和粘贴功能 |
| 选项板选择 Mixer 后右键画布 | 退出放置，选项板选择箭头恢复高亮；首次右键不弹菜单、不创建对象 | 右键与 Esc 取消放置，恢复鼠标和工具状态 |
| 组分 → 规定 → 查找 | “查找化合物”独立窗口，化合物/数据库/PubChem 标签；上方搜索准则，右侧立即查找/新搜索/帮助；下方八列结果表和添加按钮 | 恢复搜索与结果的层次，参数详情独立打开 |
| 查找 → 数据库 | 左可用、右所选“主库 子库”列表；中间 >、>>、<、<<；右侧上下箭头；窗口宽度随标签变化 | 真实数据库筛选可操作，保留只读来源与数据版本检查 |

上述菜单的出现与文字顺序已观察；没有对原版执行删除、剪切、求解或修改数据库配置。本轮新增键盘路径以应用内回归为验收，不把未逐项实测的快捷键声明为原版已核实。

## 验证记录

Windows Qt 6.8.3 构建通过，完整 CTest 2/2 通过（124 秒，启用本机真实数据库 smoke）；应用 `--self-check` 通过。新增六项交互回归全部通过，覆盖数据库筛选与添加、导航反馈、文字撤销、流程图菜单、流股命中与取消放置、多选拖动与单次撤销。最后的标签宽度调整另经原生 Windows 数据库交互/项目集成及可访问性回归复验通过。

Python 资源解析、导出及运行库测试共 13 项通过；恢复资源目录核验通过（59 个模块、3,086 个布局、289 个对话框、117 个菜单）。已人工检查原生 Windows 渲染截图中的搜索窗口、数据库双列表、设备/流股选中反馈与菜单。截图使用合成夹具，保存在本地审计目录。macOS 自动构建结果随本分支提交另行记录。

受保护数据库目录整改前后均为 3,226 个文件，逐文件路径、大小和修改时间比较一致。原始导出与归档仅本地保存，不作为截图、测试夹具或提交附件上传。

只读查询核验：本机运行库枚举到 53 个子库，数据库标签采用实测原版默认的六个子库顺序（仅在这些子库实际存在时）。默认筛选下 WATER 命中 27 条，ETHANOL 达到首批 101 条；单选 PURE41 的 WATER 命中 11 条。本轮采样分别约 0.40、1.61、0.54 秒，时间受机器负载影响。查询先限定名称匹配，再查询对应参数的来源，避免对整个目录反复扫描。没有重建或修改数据库。

已修正的关联交互包括：文件“新建”侧栏仅切面板；模拟树补设备输入页与嵌套对象，键盘导航同步页面；“仅输入”过滤在两种模式及节点刷新后保留；缩放菜单、画布与状态栏同步；导航可以收起并恢复。输入框保留自身文字撤销；项目撤销仍记录对象编辑。

流程图补充单对象复制/剪切、F2 重命名、Enter 输入、键盘上下文菜单、全选和多选删除；多选拖动作为一次项目编辑。流股副本使用新身份、偏移位置并断开端点，避免自动复制连接关系。旋转/翻转保存于对象图形字段并纳入撤销。删除菜单为额外便捷入口，继续使用确认及撤销路径。

## 保留边界

无计算后端的结果、复杂重连、模型转换和其他尚未实现的业务命令保持禁用。静态布局和菜单条目存在不代表业务完成。MW、沸点与化合物类别筛选须有已核实的数据语义才能启用；PubChem 在线查询未接入。Qt 与 WPF 的原生窗口、字体及菜单绘制仍可能不同，macOS 实机视觉和外部可访问性扫描需要单独验收。

多选复制和剪切尚未接入，对应菜单禁用。旋转子菜单采用已观察的功能区语义；该子菜单内部文字没有逐项原版核验。数据库子库顺序仅影响检索结果顺序，不代表已实现 Aspen 的物性参数选取或计算规则。结果中的分子量、沸点和类别没有填入推测值。
