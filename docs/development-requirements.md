# Aspen for Mac 开发要求与实施顺序

2026-11-19 精简版。日常逐文件任务读 [AGENTS.md](../AGENTS.md)、[执行规则](reverse-execution-workflow.md)及[当前状态](reverse-work-status.md)即可；本总纲在范围判断或阶段切换时查阅。[原完整要求和历次记录](development-requirements-reference.md)保留，按相关章节读取。

## 开发总原则

范围为 Aspen Plus、独立 Aspen Properties；Properties Enterprise Database Server 单列。各自原版安装包优先，已安装文件补缺、版本及运行证据，共享组件按归属/依赖/调用证据纳入。其他产品自身文件不开展调查或计入验收。

Plus 分类沿用冻结基线；Properties 使用需要逆向、不需要逆向、两份对应重复子集及尚未确定五份清单。未知、读取受限、路径未解析分别记录；后缀/文件头只决定初步路线，结构/内容/用途证据才能确认，内嵌代码单列。分类和阶段完成状态分开，同哈希共用分析并保留来源，同名异哈希分开。见[盘点](plus-properties-inventory.md)、[Plus](aspen-plus-classification.md)、[Properties](aspen-properties-classification.md)及[共用清单](plus-properties-shared-files.md)。

当前交付为第 2 步，按逐文件证据判定阶段验收。通过验收的逆向成果及说明同步到公开仓库的 [`reverse/01-completed/`](../reverse/01-completed/README.md)。数据库、公式、原版二进制和未完成成果仅本地保存，受保护资产遵守 [AGENTS.md](../AGENTS.md)。分类及来源/哈希/重复/安装定位/完成状态等元数据可提交到 `inventories/`，本地原件及历史快照保留。

### 1. 盘点安装包和已安装程序

记录产品及安装组件、原路径/容器成员、类型、大小、版本和 SHA-256；安装来源与已安装来源配对，同哈希共用分析、保留双方来源。安装器、载荷、内层程序、未安装选件及安装后新增项分别登记。分类复核只据实际内容证据；详细沿革见[完整记录](development-requirements-reference.md#1-盘点安装包和已安装程序)。

#### 1.1 每轮成果分类与逐文件说明

适用于每轮反编译与编译。通过对应阶段完整验收的成果放 `01-completed/`；局部、失败或未验收的放 `02-incomplete/`。新归档保留产品、原路径和文件名，每份成果配同目录同名 `.md`，写来源、版本/哈希、处理范围、状态、验收依据/证据位置、缺口及下一步，不适用项注明原因。目录汇总不代替逐文件说明；旧成果和记录不覆盖。

### 2. 逐个反编译并按原名归档

按[执行规则](reverse-execution-workflow.md)选起点，判断孤立/连锁，逐文件验收、归档和同步状态；允许按需调用子智能体，主智能体核验汇总。首次先衔接复核旧成果，具体入口见[当前状态](reverse-work-status.md)。

托管、原生、IL、VBA、资源、配置和数据库按各自格式处理；记录原版身份、工具/版本、入口、用途、依赖、证据和未核实项。从当前文件核对调用方向、输入输出含义/单位、默认值及失败行为；关键推断用原件取证，有具体验收缺口才深入外部依赖。不能由静态证据确认的运行表现列为第 3 步待验证项。源码命名与逐份说明遵循第 1.1 项及执行规则；局部成果不计为整文件完成。历史对应关系见[源码对照表](step-2-source-attribution.md)，按当前文件检索。

### 3. 先重建 Windows 版并固定基准

把已确认逻辑整理成可编辑、可编译工程，接通调用、依赖、配置与资源；记录工具链、架构及命令，在干净构建目录复现。在此阶段对第 2 步记录的待验证行为编写并运行测试：原版与重建版用相同输入、单位和操作对照，覆盖正常、边界、失败、保存重开和适用数值结果；指标及容差先定。通过后以提交固定源码、构建配置、案例和对照结果。

### 4. 从 Windows 基准复制独立的 Mac 源码

原样保留已验收 Windows 源码，记录基准提交并复制独立 Mac 工程；仅在副本替换平台接口、依赖、路径/编码、构建和打包。两套分别维护构建，记录替换及需复测功能，用同一基准案例验证。

### 5. 在 Mac 上编译并实机验收

记录 macOS、CPU、工具链和依赖版本，在干净环境构建并核对打包依赖。Mac 实机复跑 Windows 案例，检查启动、文件选择、数据库访问、打开/保存/重开及数值/失败行为，按预定单位和容差比较。分别报告自动构建、包内测试、实机与行为对照，附提交、案例及差异；分发时另验签名、公证和安装体验。
