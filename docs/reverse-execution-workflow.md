# 逐文件逆向执行规则

2026-11-19 精简版。执行开发总纲第 2 步；“完成”仅指原版逐文件逆向归档通过验收。核心约束见 [AGENTS.md](../AGENTS.md)，开始先读[当前状态](reverse-work-status.md)。详细条款见[完整参考](reverse-execution-reference.md)，只读适用章节。

## 子智能体协作

本类任务均允许按需调用子智能体，无需逐轮确认。主智能体分配必要上下文、证据、输出路径和验收要求，避免重复处理及写入冲突；所有参与者遵守同一范围和资产保护要求，主智能体核验后统一发布完成状态。

## 1. 选择文件

从[Properties](aspen-properties-classification.md)、[Plus](aspen-plus-classification.md)的“需要逆向”清单选一个未完成内容；按[共用关系](plus-properties-shared-files.md)和完成台账核对 SHA-256、`analysis_key`、来源及归档。已验收同哈希成果可复用，同名异哈希分开。优先解除阻塞、证据齐备或可多处复用的项，记录选择理由。

原版安装包载荷优先，已安装文件补充；查原路径、容器/成员、产品、版本和实际内容哈希。身份或原内容不可确认则记阻塞。开始记录轮次、清单来源/指纹、目标、验收方法、依赖及新输出路径。

## 2. 孤立或连锁逆向

模型自行判断。外部接口证据足够就孤立处理；关联实现、结构或资源直接阻碍验收时，凭引用/调用等证据加入必要的范围内文件，记录引出关系、缺口、预期成果和边界。配置、资源、数据库仍按自身格式处理；漏列程序先补来源与分类证据，不静默重分类 Plus。

每个新节点重新判断是否有证据、能推进验收且可取得进展。同哈希已完成项引用复用。目标已可验收、接口已足够、节点已处理、循环依赖、缺输入/工具/证据、无新进展或下一节点越界时停止并记录未解关系及恢复条件。循环可成组分析，文件分别验收。

## 3. 验收并归档

按原文件整体判定：来源与哈希可靠；代码/成员及必要资源有结构对照和覆盖记录；无未解释的缺失方法体、失败占位、关键类型或内部代码缺口；工具版本、操作、日志、依赖和证据可复查，区分静态结论、运行观察与推断。影响完整性的推断须解决。验收方法在处理前确定，按格式查[详细标准](reverse-execution-reference.md#31-完成判定)。

工具成功、整份源码输出、伪代码/反汇编导出、编译成功或目录名均不能单独证明完成。局部恢复保持未完成；不要求逐字原源码或一律逆向全部外部依赖。

通过验收放新归档的 `01-completed/`；其余放 `02-incomplete/`。保留产品、原相对路径和原文件全名；异版本/哈希分目录，旧成果不覆盖。整份托管完成件 `<原全名>.cs`，局部 `<原全名>.序号.cs`，分别配同目录 `<原全名>.md`、`<原全名>.序号.md`；其他格式用可识别后缀并逐份配说明。说明须有来源、版本/哈希、范围、状态、验收依据/位置、成果指纹、缺口、决策和下一步。可边做边归档或结束统一归档，过程中留检查点，本轮结束前同步状态。

## 4. 未完成项

有明确原因及新的输入/方法/证据就重试反编译或补关联分析；否则暂存，写原因、已尝试办法、成果和恢复条件。同条件不机械重试，暂存不算完成。“重新编译”不自动开启 Windows 重建。

## 5. 更新清单与下轮入口

**先验收、归档并核对成果/说明/指纹，再标完成。** 完成台账独立于分类字段，状态为未开始、处理中、未完成、暂存、已完成、待复核。记录字段及调度含义查[台账细则](reverse-execution-reference.md#51-完成状态独立记录)。

按相同原哈希及验收范围，关联更新产品总清单、适用重复子清单和共用索引的新状态视图；双归属在三方同时关联。保留来源行及原分类/历史快照，来源数与去重内容数分开统计。发布中断先补齐一致性。新版本/哈希、归档缺失或实质缺口须新建项或待复核，不沿用无效完成结论。

下轮先恢复处理中项；跳过归档可核验的已完成同内容；暂存达到恢复条件后再选。本轮收尾更新[当前状态](reverse-work-status.md)，列完成/未完成/暂存、归档/台账/清单入口及下一步。文档和允许的元数据按仓库流程提交，完整资料仅本地保存。

## 一次性衔接：既有成果

首次逆向前，从[既有归档](step-2-source-attribution.md#当前源码归档)和已登记补充归档冻结有限的历史待复核表。旧“已完成”核对原哈希、完整性、警告、逐份说明与指纹；证据充分则在新路径补齐记录并同步状态，存疑转未完成/待复核。旧未完成项逐项决定优先补齐或暂存，范围外只保留。

每项复核、归档/同步或暂存交接后退出临时规则；全部有明确处置且同步一致后本节失效，可移除临时条款并保留衔接证据，不删除原资料。旧数量仅为历史快照，不能自动继承完成结论。
