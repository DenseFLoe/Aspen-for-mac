- 两个规定下拉框按对方的当前选择裁剪候选。不能重复指定同一变量，热负荷与汽相分率不能组成一对；物料进料不提供热负荷规定。两个变量的选择顺序不改变保存的规范代码。切换前读取尚未失焦的数值输入，随后将规定及数值一起写入项目。
- 只启用当前规定的数量和单位，未启用字段的原始文本与单位继续保留，且不参与当前规定的必填/范围检查。进料还需完整组成和总摩尔流量，产品/中间流股保持由上游计算的只读边界。汽相分率为摩尔分率，单位 `1`，有效范围包含 0 和 1；热负荷允许有限的负数、零和正数。上述检查仅说明输入完整，不证明热力学可解性。
- 热负荷接入 W/kW/MW 的量纲换算。全局 SI 使用 W，其余已支持单位集使用 kW，这是本项目目前的单位子集；不宣称覆盖原版所有单位。汽相分率不随全局单位集改变。全局单位切换沿用已有事务：全部保留数量都能转换才提交，失效的未启用输入也需要先修正后才能整体切换单位。
- 项目 `processInput.version=1` 增加可选 `specification`、`vaporFraction` 和 Flash2 的 `duty`。缺失规定的旧项目按 TP 读取；非法代码、错误字段结构、物料流股的热负荷字段拒绝保存/加载。规定、数量、单位与未启用输入可保存重开并撤销/重做；“下一步”按当前规定定位缺失或非法的汽相分率/热负荷。

Flash2 的 TQ/PQ 对应 **入口热流**，不能把 Q 当作另一种数值热负荷。当前参考拓扑不支持热流连接，所以不提供这两个选项；完整 CC Nodes 状态、Heater/其他模块规定、质量基准与其他流量基准仍待各自模型及验收。阶段 3 仅扩大输入子集，阶段 5–8 和求解/结果页仍未完成。

## 本轮落实

1. **组分表右键排序**：有效记录的单元格或行头可打开“重新排序记录”，复用页面按钮的排序入口，带入当前组分的稳定身份；空白追加行、空白区域和列选择不作为记录上下文。
2. **标题双击查找**：仅“选择组分”标题的鼠标左键双击进入真实查找窗口，与查找按钮共用入口。
3. **三类组分统一多选排序**：数据库组分、用户定义对象和向导生成组分共用有序视图，显示项目 ID，以数据库/实体身份或对象 key 区分重名。支持连续或不连续多选上移/下移、边界禁用、默认定位、取消、确认、保存重开和一次撤销/重做。数据库数组的相对顺序同步保存。排序期间项目改变时，旧窗口拒绝提交并提示重开。
4. **离开编辑上下文先提交**：外壳页面/对象/对话框入口、恢复页面重建、对象页签和同一对象重新打开均提交活动编辑器，再替换视图。保存、关闭确认和“下一步”复用同一入口。正在编辑的表格单元及 Flash2 数量字段不会因导航丢失；项目恢复期间不会用旧编辑器覆盖恢复后的输入。
5. **撤销历史列表与多步跳转**：快捷工具栏提供实际项目历史列表，选择第 N 项一次恢复 N 步；重做同样支持。单次跳转只通知一次项目恢复，列表带操作摘要，历史改变后拒绝旧菜单项。编辑文本时，单步按钮交给文本控件自身撤销/重做，多步列表提示先完成文本编辑。

前三项依据[向导报告的交互扩展与漏接表](../analysis/wizard-logic-20261115/report.md)、[按钮报告 UC02–UC04](../analysis/button-logic-20261116/report.md)及[排序语义续轮](../analysis/button-logic-20261116/report-continued.md)。第四项依据[第三轮 StoreValue 发布/订阅链](../analysis/button-logic-20261116/report-round3.md)。第五项依据同一报告的列表项点击语义与续轮的文本焦点豁免。本项目使用自身项目快照实现保存和撤销，不宣称复制原版 PFS/ModelLibrary 内部数据格式、撤销记录粒度或求解能力。
