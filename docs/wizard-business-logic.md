## 项目数据与使用

从运行库添加组分后，在“组分 → 规定 → 选择”的类型列明确指定类别。查询库不含项目 TYPE，旧条目保持“未指定”，不猜测全部为 CONV。纯水电解质可使用未指定/CONV 的水；SFE 要求明确流体类别。

生成组分显示在组分表；Chemistry 进入对象树，打开查看实际反应/盐式系数；组分页显示全局 Chemistry、方法和模拟方式。保存 `.afmp` 可重开，每次向导提交对应一次撤销。源组分被生成数据引用时阻止删除及不兼容类别修改；Chemistry 重命名不破坏全局引用。

`ChemicalSystem` 独立于控件实现业务规则。项目版本仍为1，新增可选 `chemicalSystem`（内部版本1），含 `generatedComponents` 与 `global`。Chemistry 对象新增 `chemistryData`，保存反应、盐式、参考态和模拟方式；系数使用十进制字符串。数据库组分引用 database+compoundId，用户组分引用对象 key，生成组分有独立 key，全局 Chemistry 引用对象 key。

旧 `unverifiedInputs.assistants` 配置保留，但不自动执行或恢复成业务结果。原有对象未验证输入也保留；实际 Chemistry 使用独立只读视图，避免业务记录再次变成控件快照。本轮另修复组分表定位：显式绑定“选择”页，避免页签升降改变 findChild 顺序时误写石油表格。

## 继续查证与未实现边界

本轮复核 `SFEAssistantStep2.Loaded/GenerateComponent/GenerateChemisty/GenerateReaction/OnFinished/ValidName` 方法体，确认名称/别名传递、全局分支差别和字符范围。再查 native 记录：`exclude_aq@0x1d09f0` 跳至 `0x1d0a30`；`rem_rxns@0x1d2340` 经 `0x1d2380` 重入 `genrxns@0x1d10f0`，因此候选删除不能只删 UI 行。但 `genrxns` 间接跳转和 APED 深层筛选尚未产生完整可移植规则。

通用 APV 反应库枚举/选择、H+、成冰、其他电解质体系和 Henry 生成仍未实现。欢迎页显示已核实 WATER 案例，不伪造 APV150 反应库；不支持请求在候选页阻止提交。二级反应编辑器的增删、平衡式校验和取消事务尚未解明，本轮提供真实记录的只读视图。新固体/离子是项目数据，不向 APED 插入记录；没有生成纯组分参数、平衡常数或模拟结果，不改变后续计算阶段的验收状态。
