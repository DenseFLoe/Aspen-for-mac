# Flash2 参考案例连接规则

2026-11-17，分支 `codex/flash2-topology`，继承字段、单位及引导基线 `e5768c0`。本轮继续落实[下一步流程研究](next-guided-workflow.md)和[开发顺序](development-requirements.md)中的连接前置条件，推进阶段 4 的参考案例子集。

## 已接入行为

参考依据为[原版案例](../analysis/next-guidance-20261117/case.json)：一个 Flash2、一个外部物料进料、一个汽相产品和一个液相产品。新增独立 `ProcessTopology` 规则，供画布操作和 `ProcessGuidance` 共用；不按流股显示名称推断相态。

- 流股以 `from` / `to` 引用稳定模块身份，以可选 `fromPort` / `toPort` 保存端口。参考案例约定 `FEED` 为进料、`VAPOR` 为汽相出口、`LIQUID` 为液相出口；这些是本项目格式标识，不是原版内部端口编码。
- 画布显示三个端口标记。直接点标记可指定端口；点 Flash2 本体作为源时须明确选择汽相或液相，作为目标时连接唯一的物料进料。已占用端口给出原因并阻止确认。
- 新建和重连都检查方向、占用、失效模块及模块自连。热量和功连接在本参考案例中明确阻止；不表示原版 Flash2 没有其他规定方式。其他设备继续使用既有对象连接方式，不能据此视为已具备端口语义。
- 取消出口选择、新建连接失败或重连失败不写入项目，也不创建半条流股。端口选择确认后再次检查当前模型，取消放置或恢复项目后，旧对话框不能写回连接。
- 断开端点和删除模块同步移除相应端口；移动、重命名不改变引用或汽液角色。连接及角色随项目保存、重开、撤销和重做。复制流股沿用自由端点策略，不复制端口占用。
- 旧项目没有端口字段时原样加载、保存，不自动给两个产品分配相态；“下一步”选中需要补选端口的流股，状态栏给出原因。可右键流股，使用“重新连接源/目标”补齐。错误类型的端口字段会阻止加载/保存，保存失败保留原文件。
