## 取样与分类依据

- 直接扫描两个产品在 Program Files 和 ProgramData 的产品目录及 APED V15 数据目录。查询本机 Windows Installer 的产品注册、已落盘组件和缓存 MSI 文件表，并结合两产品已有的精确安装目标证据，核对共享目录及 GAC 的实际文件。APED 文件记录为物性配套来源，其他产品只纳入有两产品归属证据的具体文件。
- 对每件实际文件读取完整 SHA-256。历史四份分类 CSV 和 Properties 安装定位记录先与发布清单的 SHA-256 核对，再用内容哈希和大小匹配旧分类。可读、已确认且无分类冲突的结论可复用。
- 检查已识别的 Office 容器代码目录。6 个旧标“不需要逆向”的工作簿检出内层 VBA 模块流，本次改列“需要逆向”。按宿主指纹和内层成员记录流指纹。37 个 Office 宿主中，12 个检出内层代码，共 164 个宿主成员位置、156 种不同流内容。
- 8 个实际 SQL Server MDF/LDF 文件无可复用的旧内容哈希。本次通过本机 `sys.master_files` 对照实际物理路径重新确认其为数据库数据或日志文件。

本轮现场快照、来源证据与校验记录位于本机 `.local/installed-plus-properties-20261124/evidence/`。
