# 待核实文件的后缀抽样与分类复核

2026-11-18 开发范围更新：本次只评估 Aspen Plus，其他 Aspen 产品暂不进行开发评估，详见[开发总原则](development-requirements.md#开发总原则)。下文全来源数量保留为历史扫描记录，不能直接作为本次 Aspen Plus 的分类欠项。当前已扫描的首选 Aspen Plus 安装来源分类待核实数为 **0**；全来源剩余的 7,170 条均为备选来源记录，其中 HYSYS 目录 6,924 条、EDR 目录 191 条，其他产品目录 55 条。其他产品自身的文件暂缓；共享组件仅在有证据确认被 Aspen Plus 使用后，按相关部分单独纳入，不能只按目录名判定依赖关系。

2026-11-18 按用户要求，对首次扫描中未核实清楚的文件按后缀调查。涉及 **67 种后缀，选取 504 个不同内容或读取受限样本**；其中 492 个样本取得完整内容并复核 SHA-256。首选安装来源原有的 **389 条待核实记录全部覆盖其不同内容哈希**，其余来源按后缀取不同内容补样。安装包仍为首选，已安装文件仍为备选。

复核后，首选来源的 389 条记录均已确定本轮处理分类。此结论只表示知道文件应走代码恢复、资源提取或数据解析路线；模型解密、完整格式解码、反编译、编译和行为验证分别验收。

## 备选来源及读取限制

备选抽样识别了 HYSYS 案例/组件列表、能量分析案例、语言资源、数值表、公用工程数据库、原油评价数据库、偏好设置、CAD 零件、视频、绘图及帮助项目等。这些文件按数据或资源处理；完整格式解析和内部扩展审计仍有各自的范围限制。`.psc` / `.ptb` 样本属于 `vr 8` 编码的脚本/项目组件族，正文尚未解码，保留逆向候选及待核实标记。

8 个 MDF/LDF 现在通过只读 `sys.master_files` 查询确定为 SQL Server 数据/日志文件；4 个无后缀 APED 文件通过 `RESTORE HEADERONLY` 确认为完整数据库备份。没有执行恢复、停止服务或修改数据库。对 8 个原始数据/日志文件的只读打开均返回 Windows 错误 32（共享冲突），因此原始内容及哈希仍不可读；分类为数据库文件已经有独立元数据依据。

6 个 HYSYS ZIP 的 6,281 个加密成员仍只登记名称和大小，内容没有读取或解密。全清单尚有 7,170 条待核实标记，其中 6,281 条为上述加密成员；其余 889 条包括未抽样的不同内容和编码未解的项目。首选来源的分类标记已核实完，不以此宣称其余来源已逐文件验收。
