## 阶段 1 实现

- `ProjectDocument` 独立持有项目 JSON 和最多 100 步基础撤销历史，不依赖页面控件。窗口编辑适配器同步对象、输入和全局单位；保存从项目模型读取。
- `.afmp` 是版本 1 的 UTF-8 JSON 自有格式，保存稳定对象身份、父子关系、流股连接、坐标、用户组分及原有页面输入。格式预留真实组分身份和数据依赖；不兼容 Aspen 原版案例文件。
- 未核实的页面输入保存在 `unverifiedInputs` 和对象 `inputs`，原始字符串保留，未伪装成已验证的类型、量纲或计算输入。方法选择也作为原有页面输入保存；字段语义和单位换算仍属阶段 3。
- 文件菜单和平台标准快捷键支持新建、打开、保存、另存为、关闭；未保存修改有保存／放弃／取消提示。撤销重做覆盖创建、重命名、删除、输入修改、图形移动及连接创建；复制和连接创建作为整体撤销。
- `QSaveFile` 禁止直接覆盖回退，只有临时文件完整写入后才替换目标。读取先完成版本、结构、对象类型和引用校验，失败不修改当前项目。撤销恢复包含子对象与连线；恢复后清空失效导航历史和旧剪贴板。
- 当前项目大小上限 64 MiB；撤销历史不写入项目文件。页面导航、临时弹窗和窗口排列不属于业务项目；旧页面尚无完整字段校验。

6. 运行打包脚本，启动复制后的应用包，再验证文件选择、保存重开和数据库访问。正式签名及公证另行验收。
