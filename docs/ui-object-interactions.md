## 原版直接观察

在本机 Aspen Plus V15 的未保存 `Simulation 2` 空案例中通过原生窗口操作观察：

| 操作 | 观察到的结果 | 本轮接入 |
| --- | --- | --- |
| 打开物性组管理页，点击新建 | “创建新ID”默认 `PS-1`；确认后新增左侧 `PS-1` 节点并打开对象页，含物性、限定符、注释 | 对象列表、导航节点、独立页签和三个资源标签 |
| 物性组右键重命名 | 打开预填现有 ID 的输入窗口；本轮取消，未确认原版改名成功 | 本地重名校验、改名后的标题/树/列表同步，由 Qt 测试验证 |
| 物性组选择一行、复制、粘贴 | 无选择时复制不可用；同名粘贴出现“解决 ID 冲突”；选中冲突后可“编辑 ID”，再出现“对象名称”窗口 | 编辑新 ID、回到冲突页、最终确认后才创建副本；取消不创建 |
| 模块管理页点击新建 | 默认模块 ID，类型未选时确定禁用；类型列表可展开 | 同样的类型选择门槛；此处原版取消，未验证所有类型的创建 |
| 流程图模型库选择 Mixer，点击画布 | 增加 `B3` 图形与左侧模块节点；退出放置后双击图形打开 `B3 (Mixer)` 输入 | 放置、节点联动、双击打开、关闭后重开；图形使用通用标记 |
| Mixer 初始输入 | 闪蒸选项/注释；压力 0 bar、有效相态汽-液、温度估值空 C、最大迭代 30、容差 0.0001 | 对应默认值及会话输入；完整相态候选集没有据此推定 |

原版重命名及粘贴的编辑窗口只核对了弹窗和取消路径，未将原版输入工具的焦点失败算作成功。原版测试对象未保存到案例文件。原版替换/合并冲突按钮的语义尚未接入；当前粘贴只实现作为新对象的路径。

## 可操作的对象关系

`ui/object-types.json` 声明 15 类集合、95 种对象类型，包含 67 种有根输入/设置布局的模块。每个入口都引用实际目录中的页面。Mixer 及物性组的主要创建链经过原版观察；其余类型采用共享对象框架，类型到输入页的映射来自静态命名空间，不能算作逐模型动态核实。

| 集合 | UI 行为 |
| --- | --- |
| 物性组、化学反应、单位集、分析、反应、灵敏度、设计规定、计算器、优化 | 新建 ID → 对象节点/列表行 → 独立输入页；支持重命名、复制为新对象、删除 |
| 模块 | 新建时选择类型；支持从模型选择器放置到流程图、双击输入、拖动位置 |
| 流股 | MATERIAL / HEAT / WORK / POWER 输入页；画布两次点击指定端点，可附着模块，移动模块更新连线 |
| RadFrac 子对象 | 导航中设计规范、调整变量、中段回流集合可新建子对象；父对象复制携带子对象副本，删除父对象一并删除子对象 |
| 用户定义组分 | 向导前进/后退保留输入；完成后新增组分行及对象节点；常规/固相/非常规取自静态选项；取消不创建 |

实现使用稳定对象标识关联页面、树节点、流股端点和导航历史，重命名不改变标识。删除时同步清理打开页签及失效历史；删除模块会解除流股附着关系。关闭对象页仅释放视图，输入状态仍在本次会话内；复制取得输入快照，后续修改互相独立。

对象页的文本、勾选、选项、注释、页内标签和表格行可保留。表格填写最后一行会增加空行，右键可删行。没有恢复候选列表的输入可暂存手工文本，不执行 Aspen 取值校验、计算或单位换算。记录的 ID 校验采用本地 1–8 位字母/数字/连字符/下划线及同集合不区分大小写唯一规则，未声称覆盖原版全部命名例外。

## 明确剩余范围

1. 运行时决定的模型选项、条件显隐、联动候选项、专有图表/第三方控件，尚未逐项恢复；未接入动作保持禁用。条件布局预览不等于原版状态机。
2. 11 个缺少布局的引用仍保留缺口；95 种对象是已接入的声明集合，不代表整个 Aspen 对象模型。
3. 流程图是 UI 会话编辑器：通用模块标记及连接线，尚未复刻完整模型符号、端口类型校验、子流程图和路由规则。
4. 冲突替换/合并、文件导入导出、撤销重做、跨会话保存尚未实现。退出程序会丢失输入；不生成物性或模拟结果。
5. 数据库、其明文导出和归档完全独立，本轮没有修改、覆盖或上传受保护数据资产。
