2026-11-16 更新：本文的向导表格是旧版配置存储里程碑。SFE 业务写入及有限纯水电解质链已在后续工作分支接入，准确范围与剩余边界见 [向导业务逻辑](wizard-business-logic.md)，不再以本页旧表推断当前实现。

## 证据与覆盖范围

- 原版：本机已安装 Aspen Plus V15，中文界面，未保存的 Simulation 1；先以 WATER 观察电解质流程，之后原版生成了 H3O+、OH- 和 GLOBAL 化学反应。未保存为用户项目文件。
- 对照 `ui/recovered/sources.json` 的 59 个来源文件重新核对已安装文件 SHA-256，全部一致。复用对应的本地完整资源扫描，重新生成菜单目录；本轮没有重新解包安装介质，也没有将安装文件或数据库上传。
- 静态目录覆盖 59 个模块、3,086 份布局、117 份菜单资源，递归枚举 1,365 个菜单节点，当前资源最大深度为 3。布局数量包含控件片段，不等于业务页面数量；动态追加的菜单仍需运行时观察。
- `tools/audit_ui_operations.py` 可生成完整本地清单，列出所有菜单路径及 9,136 个按钮／菜单／选择器／表格候选节点。候选数包含列定义、转换器和数据项，不可作为可操作控件数或完成百分比。
- 本地证据和报告：`.local/ui-operation-audit/installed-resource-verification.json`、`operations.json`。原数据库资产未用作工作目录。

## 共性修复

1. 组分页四个按钮原为纯文字配置，无命令 ID，被渲染器禁用；现在明确绑定到已有命令和新增向导流程。
2. WPF 的 `True`／`False` 字符串与 JSON 布尔值统一解析；复选框嵌套文本、列表和 DataGrid 列结构恢复，避免选中状态和表格丢失。
3. 向导输入保存到项目的 `unverifiedInputs.assistants`，普通字段编辑不会再覆盖此扩展数据；尚未验证业务语义的输入不冒充计算结果。
4. 数据库衍生表格刷新阻断修改信号，避免保存／撤销期间把显示刷新当成用户编辑。
