## 应用使用

1. 打开“组分 → 规定 → 选择 → 查找”，或功能区“查找组分”。
2. 首次点击“选择数据库…”，选择新运行目录里的 `catalog.sqlite`。路径保存在本机 Qt 设置中；也可以用环境变量 `ASPEN_PROPERTY_DATABASE` 指定。项目只记录数据集身份，不保存本机绝对路径。
3. 按名称、CAS、别名或同义词检索。精确匹配优先，最多显示 100 条；结果超过上限时提示缩小条件。`%`、`_` 按普通字符检索，查询使用绑定参数。
4. 选择结果查看原始参数和子库，每页 200 条；点击参数查看文献、注释、单位及原始文件哈希。空数值显示“无原始数值”，不作为零处理。
5. 点击“将选中组分加入项目”。已选项可移除并撤销，主组分表同步显示；保存 `.afmp` 后关闭重开可恢复数据库／实体 ID、名称、CAS 和数据集来源。

应用通过 Qt SQL 的 `QSQLITE_OPEN_READONLY` 打开运行库。库缺失、版本不兼容、结构损坏或构建未完成有明确提示。项目引用不同数据集时提示连接原版本；已有身份仍保留，禁止混入另一版本的组分。不同主库的同名条目保持独立身份。

## Mac 应用包

依赖 Qt Widgets、Test、Sql（包含 SQLite 插件）。按 README 构建后运行：

```sh
sh tools/package_macos.sh build "$(brew --prefix qt)"
```

脚本在 `build/macos-package.XXXXXX/` 新目录复制应用，部署 Qt 依赖，检查 SQLite 插件，并运行 `--self-check` 验证打包后插件加载和项目往返保存，再生成本地 ZIP。不会清理旧目录，不自动上传构建产物或数据库。GitHub Actions 执行同一依赖检查；该检查不替代 Mac 实机验收。正式签名、公证及安装体验仍在后续分发阶段。
