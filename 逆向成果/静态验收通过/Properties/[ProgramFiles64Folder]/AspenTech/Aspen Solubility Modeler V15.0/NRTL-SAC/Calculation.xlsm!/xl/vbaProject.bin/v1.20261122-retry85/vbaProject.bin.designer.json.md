# vbaProject.bin.designer.json

frmHTE 窗体资源来自 Aspen Properties V15 安装载荷的 Properties/[ProgramFiles64Folder]/AspenTech/Aspen Solubility Modeler V15.0/NRTL-SAC/Calculation.xlsm!/xl/vbaProject.bin，内层工程无独立版本。原件 SHA-256 为 2ee31997f86026cbc84fdda380790a4ca2c9a4805358b29c1991cfc9b755ba10。

CompObj、VBFrame、f、o 四流以 Base64 保留，解码后分别比对字节和 SHA-256。实际 OLE 流名写在 stream 字段。controls 字段映射四个 MSForms.Label 的名称、位置、尺寸、标题、顺序和原流偏移。位置和尺寸使用 HIMETRIC 单位。VBFrame 保留窗体属性，f 和 o 保留控件的完整二进制属性。窗体的 VBA 源码见 vbaProject.bin.frmHTE.frm.vba。

静态资源和布局覆盖通过。分流格式可按原流名放回复合文档的 frmHTE 存储。Excel/VBE 窗体导入与显示行为留待 Windows 验证。
