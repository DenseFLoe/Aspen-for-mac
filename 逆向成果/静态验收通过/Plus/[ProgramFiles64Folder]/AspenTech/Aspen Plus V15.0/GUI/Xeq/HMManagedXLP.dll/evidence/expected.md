# HMManagedXLP.dll 冻结源码包独立复核预期

复核员 `/root/reviewer`。本记录在打开送审文件和运行用例之前编写。适用基线为 GitHub main 固定提交 `adbe73b517acac25da87598cce46de033f630ccb` 的 `docs/static-acceptance.md`。

| 用例 | 输入与操作 | 预期 |
| --- | --- | --- |
| 身份、清单和边界 | 计算冻结 ZIP 和本机原件 SHA-256。先用标准 ZIP 库列出成员，检查 CRC、路径、逐项指纹和未记项。静态审查构建入口及比较入口。 | ZIP 为 `b4fb8a3812d880be5f6bdaadcb3f7b0dc3a1a418a8f01af8f33cae92cec097a1`，原件为 `3186d51b396c281ab10ae71c5ba00d6cebdae09bf17eabacb0a08a24ff556e7f`。包只有可编辑源码、公开公钥、构建和比较脚本及必要证据。构建链仅直接调用编译器，入参带源码、公开公钥和引用，比较另读原件。 |
| 空目录复编 | 无原件参数，将冻结 ZIP 解到独立空目录，使用已登记的三项外部构建输入。再以仅含构建脚本、可编辑源码和公钥的新目录重复。 | 两次均直接输出相同 SHA 的 DLL。无 .NET SDK、Excel、PE 复制或回放输入。 |
| 结构与实现 | 共享 CLR 验收器直接读取两份 PE，独立用 System.Reflection.Metadata 和原始方法体完整字节复核同名定义、实际代码、EH、ModuleRef 和必要表。 | 665 条 MethodDef 配对。406 个有 RVA 实现与 259 个无体 P/Invoke 声明分别吻合，17 MethodImpl、2 FieldMarshal 和 21 CustomAttribute 完整。真实产物同安装原件。构建生成的 MVID、调试和签名能解释。 |
| 资源与 PE | 使用 pefile 读取两份 PE 原始资源树、装载头字段、导入、引导入口、签名槽及证书表。 | 托管资源为零，原生版本资源 `16/1/0` 的完整数据一致。保留程序集公钥与身份，公开签名阶段不生成 Aspen 实际加密签名或证书。 |
| 可编辑方法负对照 | 另建干净试验目录，选一个确定含方法体的整数或布尔等可控表达式，仅改一个行为值。重建并比较，另外记录变体的源码和 DLL 指纹。 | 构建成功、候选指纹变化，正式比较不能通过，IL 检查具体指出至少一个方法差异，原生版本资源仍相同。 |
| 结构及资源负对照 | 基于同一冻结源码，独立地只改一个程序集文本特性。若资源亦由此构建生成，另以单独的等长 PE 资源载荷变更分离该维度。 | 特性变体可编译但 CLR 元数据检查报告差异。资源单项变体的托管实现比较仍通过，PE 资源检查报告差异，整件比较不通过。 |
| 运行边界与依赖 | 从原件读取 AssemblyRef 和 ImplMap，从装机同目录解析外部提供 DLL 的导出，核对已知托管调用方 AssemblyRef。 | 目标程序集无直接 Excel COM/Interop AssemblyRef 或 ModuleRef。外部 `hmxlpxmps` 声明从实现和调用方角色分开核对，现场若确有缺名，保留原件结论并归入宿主后续验证。 |
