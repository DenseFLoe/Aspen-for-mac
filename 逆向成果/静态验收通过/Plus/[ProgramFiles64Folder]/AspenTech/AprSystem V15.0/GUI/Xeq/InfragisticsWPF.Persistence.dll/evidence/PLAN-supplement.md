# 补充负控预注册

开始负控前增加以下两个用例。每个用例只修改复编 PE 的一个字节，不改变方法体、资源身份或物理布局。为每个输入重新计算交付指纹。

- 改同一实际 CIL 调用目标的 MemberRef 名称 `RegisterAttached` 中的最后一个 ASCII 字母，长度不变。方法体内 token 和 IL 字节应保持一致，独立方法绑定列表与完整元数据以及包内 `definitions_and_bindings` 必须报告差异。资源应全等。
- 修改 Win32 VERSIONINFO 的 UTF-16 字符串现存版本文本一位数字。选中已哈希确认的 1,138 字节叶内容区域。预期只有 Win32 资源项失败，CLR 元数据、方法体与托管资源保持一致。
