# 发布包和逐包核对

[原发布页](https://github.com/DenseFLoe/Aspen-for-mac/releases/tag/v0.20261121-w2) 有五个压缩包。解开的文本位于[原件文件夹](../../../逆向成果/)。同一原件中内容和格式相同的副本共用一个文件，内容不同的版本分别保留。大于 48 MiB 的文件按字节顺序分片，分片目录附有完整 SHA-256 及拼接方法。

`assets.json` 记录五个原包的大小和 SHA-256。`part1.jsonl` 至 `part5.jsonl` 将每个原包成员对应到原件、内容指纹和目标路径。[核对回执](核对/) 记录 GitHub 实际解包的结果、文件或分片的 Git 指纹。`layout.jsonl.gz` 是生成目录和说明的机器清单。

5 个包共 4,276 个成员，涉及 1,177 个不同原件。按原件、格式和内容去重后共有 2,690 份文本。包中没有独立的 W2 报告，各原件的“归档说明”由整理时生成；旧分支已有的制作者报告保留在“分支交付”中。
