# 发布包、报告和逐包核对

[原发布页](https://github.com/DenseFLoe/Aspen-for-mac/releases/tag/v0.20261121-w2)的五个包已在 GitHub 解开。4,276 个成员对应 1,177 个原件，按原件、格式和完整内容指纹去重后保留 2,690 份文本。6 份超大文本按字节分片，可按目录里的说明恢复。

[按原件浏览](../../../逆向成果/) · [制作者逐件报告对照](W2报告对照.csv) · [制作者原始索引](制作者索引-index-w2.csv) · [核对回执](核对/) · [验收状态路径变更](验收状态路径变更.csv)

`assets.json` 记录原包大小和 SHA-256。`part1.jsonl` 至 `part5.jsonl` 记录实际成员、原件 SHA、内容 SHA 和解包时目标。核对回执列出正文或各分片的 Git 指纹；目录后续根据逐件报告调整的，以上方路径变更表为准。[解包完成快照](https://github.com/DenseFLoe/Aspen-for-mac/tree/4af720e436922909f0696d75733daf4e919b100f)可直接按当时的路径读回。

压缩包里没有单列 Markdown。随后对方在主分支上传了 1,257 份 W2 报告，原件目录中标注为“制作者报告”。“归档说明”由本次整理生成，依据实际文件及指纹对应代码和报告。报告所列分包或文件指纹与实物有出入的，以解包回执为准。
