`out/R2/check_clone.py`（`tools.write` 落盘，逐字）：

```python
import hashlib, pathlib
root = pathlib.Path('Aspen-for-mac-main')
before = {}
for line in pathlib.Path('out/R2/clone-before.sha256').read_text(encoding='utf-8').splitlines():
    rel, h = line.split('|'); before[rel] = h
now = {}
for p in sorted(root.rglob('*')):
    if p.is_file() and '.git' not in p.parts:
        now[p.relative_to(root).as_posix()] = hashlib.sha256(p.read_bytes()).hexdigest()
diff = [k for k in before if before.get(k) != now.get(k)]
extra = [k for k in now if k not in before]
print('CLONE-CHANGED changed=' + str(len(diff)) + ' extra=' + str(len(extra)))
```

期望 `CLONE-CHANGED changed=0 extra=0`。非 0 ⇒ 停手上报（含 `diff` 前 5 条），不许自行删除克隆里的文件。
