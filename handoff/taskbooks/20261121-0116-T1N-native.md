## 5. ExportAll.java 契约（逐字照抄；r3 双 I5）

**调用串**（由 `native_reverse.py` 拼，不许改成多段）：

```bash

  -import "out/R1N/stage/<safe_key>__<NAME>" [再重复 -import …] \
  -scriptPath tool/ghidra_scripts -postScript ExportAll.java "<abs outdir>" \
  -analysisTimeoutPerFile 600
```

- staging 文件名 = `<safe_key>__<NAME>`（唯一化：本轮有 4 份同名 `userfort.dll`，直接 `-import` 原名会撞）；程序名即此名。
- `ExportAll` 入参：`args[0]` = 输出目录；取 `currentProgram`，输出两个文件：
  - `<outdir>/<programName>.asm.txt`：首三行 `# LANG <language id>` / `# BASE <image base hex>` / `# BLOCKS <n>`；随后每函数 `FUNC <addr> <name>` + 指令行 `  <addr>: <mnemonic> <operands>` + `ENDFUNC`。
  - `<outdir>/<programName>.c.txt`：每函数 `// FUNC <addr> <name>` + C 正文 + `// ENDFUNC`；反编译抛异常写 `// DECOMP-FAIL <addr> <name> <ExceptionClass>`。
- **恒等式**（逐 PE）：以 `^FUNC ` 开头的行数 == 以 `^// FUNC ` 开头的行数 + 以 `^// DECOMP-FAIL ` 开头的行数，即 `FUNC == //FUNC + //DECOMP-FAIL`。`decomp_fail` 可 >0，但必须打印并写进 `.md`。
- 单 PE 超 600 s ⇒ 该件 `status=failed_analyze`，不写伪造产物。
- 落位：`native_reverse.py` 把 `<programName>.asm.txt` 重命名成 `01-completed/<Product>/<DIR>/disasm/<NAME>.asm.txt`，`.c.txt` → `decompiled/<NAME>.c.txt`；`analyzeHeadless` 的 stdout 存 `__raw/<safe_key>/import.log`。

```python
import pathlib
root = pathlib.Path('out/R1N/01-completed')
bad = 0
files = 0
for asm in root.rglob('disasm/*.asm.txt'):
    c = asm.with_name(asm.name.replace('.asm.txt', '.c.txt')).parent.parent / 'decompiled' / asm.name.replace('.asm.txt', '.c.txt')
    f = sum(1 for l in asm.read_text(encoding='utf-8', errors='replace').splitlines() if l.startswith('FUNC '))
    d = sum(1 for l in c.read_text(encoding='utf-8', errors='replace').splitlines()
            if l.startswith('// FUNC ') or l.startswith('// DECOMP-FAIL '))
    files += 1
    if f != d:
        bad += 1
        print('MISMATCH', asm.name, 'FUNC=', f, 'entries=', d)
print('IDENTITY files=' + str(files) + ' mismatched=' + str(bad))
```
