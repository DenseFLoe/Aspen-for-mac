# ppexec.dll 的导出存储和版本资源

本目录以版本 41.0.0.605 的原件及首轮 `code/references.asm` 为输入。SHA-256 为 `d93227b9a8f77c09fc1294834b6a4d87ba03a0697a680039fdce35cb1ce4549a`。使用 pefile 2024.8.26、iced-x86 1.21.0 执行 `python check-data.py <原件> <首轮 references.asm> --check` 即可复核全部四个数据文件。

26 个数据导出位于 .data 段。首个导出 PPEXEC_REINIT 位于 RVA 0x1e8c0，该节虚拟末端为 0x22150。二者之间 14,480 字节的映像初值全部为零，其中 320 字节可在原文件读取，余下 14,160 字节由 PE 节映射补零。该范围没有基址重定位。export-intervals.csv 列出序号、地址及到下一导出或节末的距离。保留这些间距可还原相对布局。导出名之间可能还含私有变量或填充，外部声明及实际使用证据仍决定各变量类型和长度。

storage-references.csv 共 1,280 个不同指令位置，逐条以 RVA 回读原始指令并交给 iced-x86 解码，58 处直接引用导出基址。其余行给出到前一导出标签的距离，供定位字段或其他变量。间接寻址和由寄存器计算的地址留待对应函数核对。此表固定使用首轮反汇编，后续引用索引保留其各自范围。

唯一资源是 RT_VERSION 1/1033，code page 0。version-resource.json 保留固定版本结构、语言、代码页、字符串顺序和结尾字符。脚本对提交中的可编辑树编码，重新生成的 800 字节与原件完全相同，SHA-256 为 `a0c11895911a8f526a9006e29f320cedc913c9d4c59e770f35a4c82f0617ddc3`。
