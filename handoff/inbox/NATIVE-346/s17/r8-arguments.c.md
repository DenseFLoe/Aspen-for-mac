# ppexec.dll 第十七号 R8 源码模型

原件 SHA-256 `d93227b9a8f77c09fc1294834b6a4d87ba03a0697a680039fdce35cb1ce4549a`，41.0.0.605。模型覆盖六组条件和八个调用位置的 R8 字节数准备。`element_count` 记录通过正值分支的元素数，`r8_byte_count` 用于批量调用。`0x7e5a`、`0x7e70`、`0x7e86` 共享计数和一次乘八。`0x565e` 的填充字节为零，`0x79fa` 的填充字节为 `0x20`。

在 C11 中用无符号 64 位左移重现原件的寄存器值。调用缓冲区及其声明范围见 [逐址说明](contracts.md)。交付状态为局部模型。与 [固定输入和原件指令](evidence.json) 对照，并以 Zig 0.13.0 的 Windows x86-64 GNU 目标编译对象文件。
