# zedstwu.dll 复制和导入跳板实现

`zedstwu.c` 使用 C 的模块级 GNU 汇编表达 Windows AMD64 寄存器、指令及条件标志。0x16560 至 0x1760a 之间的内部标签可直接互跳。原件以两种可能的寄存器方向编码某些等价指令，RR64 宏以操作名和源、目标寄存器明确保留相应编码。具有指定长度的条件与无条件跳转以操作码及符号间距表示，避免重组时缩短分支。每个原始对齐区都标为 alignment。128 个导入跳板用各自的加载器 IAT 地址标识符表示。跳板保留调用方的寄存器、栈及返回地址。[实现](zedstwu.c) · [原件、版本、核验范围及缺口](../zedstwu.dll.md)

四张表的可编辑定义按原索引写出代码标签。两个可写全局量分别位于初始数据及零填充存储。`verify.py` 从编译产物读取文本、数据、BSS、符号表和重定位，以固定的原件 RVA 和基址核验 4,266 字节复制代码、768 字节跳板、217 个指针和两项全局初值。表中地址保留 Windows 装载时可重新定位的关系。[数据源码](copy-data.c) · [逐项证据](../copy-tables.csv) · [编译复核](../rebuild.json)
