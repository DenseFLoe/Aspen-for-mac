# zedstwu.dll 初始化器静态数据

原件版本、路径、指纹和范围见 [初始化器说明](initialize-capability-records.c.md)。本文件恢复三块数据。Vendor 字符串 RVA `0x1a160` 占 16 字节，由 `0x14970` 读入。描述符表 RVA `0x1a170` 包含 255 个可被索引的八字节条目。`0xff` 触发清零，余下字节值查表。`0x235f0` 起的 64 字节由加载器清零，依次放置四个元数据 dword 与三个 16 字节缓存记录。就绪标志位于 `0x235fc`。

独立编译后，Vendor 和可达描述符表 2,056 字节与原件对应范围相同。64 字节存储匹配原件可写节的零填充区域。各范围指纹及布局见 [回编记录](reassembly.json)。
