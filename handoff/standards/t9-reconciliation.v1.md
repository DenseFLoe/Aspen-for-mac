# T9 预审报告交叉核对 v1

1. 使用分配卡固定的提交和六个文件。按原始字节记录 SHA-256。从两个 CSV 逐行比对 idx、分片、归档状态、产品、名称及对象路径，查验 0–999 完整性、路径唯一性、台账 SHA-256 格式和重复。选择表没有原件摘要时明确其来源。
2. 按台账重算四类预审结论、各产品和归档状态的分布、各失败原因涉及的独立行数，以及 Tier A/B 的行状态。多个失败原因可共存。复核 stats、failures、validation、README 的总数、分组、原因、明细及更正范围；冲突给出位置、行身份、正确信息和恢复条件。
3. 固定结果保存在 `inbox/T9-368-RECONCILE/reconciliation.json`，提供摘要及反例。Python 3.9+ 从仓库根运行任务卡命令。可用 `--input-dir <六个原始文件所在目录>` 离线复跑。默认退出 0 表示报告与固定输入的独立复算相符。只有 PR 的各项对照一致后，上游才可接收相应预审文档；原件级最终状态按逐文件标准判定。
