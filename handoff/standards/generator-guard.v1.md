# ILSpy 生成端尾部提示门禁 v1

两处生成入口的最终 `.cs.txt` 应只剥离 ILSpy 在源码后追加的已知、完整两行升级提示。按原始字节比较，保留源码的 UTF-8 BOM、LF/CRLF、空行和源码字符串内的同文提示。仅有提示时输出为零字节。提示第二行没有末尾换行时也能识别。剥离后再次处理，输出仍须相同。

交付前扫描对干净的 `.cs.txt` 返回 0，对仍含终端工具提示或未配对裸诊断的文件返回 1。生成器遇到未配对提示须保留字节供门禁报告。C# 多行字符串中出现相同文字时，门禁应允许该合法源码通过。这些标准覆盖本次固定版本 ILSpy 提示的字节行为。

## 输入与判定

上游判定器内固定十组用例，包括干净且没有末尾换行、源文件末尾空行、空源文件、LF 提示、含 BOM 的 CRLF、提示末行无换行、仅提示、源码字符串中的同文、字符串后另有真实提示、未配对裸提示。每个用例分别核对两个写入入口的首次与二次输出、扫描器对写入前后文件的退出码，共 20 组。

按任务卡固定的提交核对生成器和门禁源码、生成命令以及真实输出。逐字节校验退出 0 表示提交方数据满足上面 20 组断言；上游还须确认输入、实跑记录和两处生产路径一致，才能对候选 PR 作裁定。输出或门禁退出码有差异时，按用例列举原始输入、期望、实得及对应源码位置；缺少实跑记录或无法确认来源时记录恢复条件。
