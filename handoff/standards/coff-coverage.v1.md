# AMD64 COFF 单件覆盖 v1

适用于 COFF-BFDYLD。按任务卡固定的提交、原路径和完整 SHA-256 校验字节。对照 COFF 节头、符号及辅助记录、重定位与代码，列出所有有内容的节和未初始化空间。记录 .text 中的函数、代码范围、对齐填充和其它数据，保留可编辑汇编、可追溯的原始位置及恢复说明。

外部目标按节内偏移、类型、符号及原件加数核对。区分直接调用、数据引用、展开信息和未解析的外部实现。检查器须使用固定原件独立重读 COFF 表，校对交付中的覆盖记录。使用汇编器重新生成测试对象后，比对代码字节及其关联重定位，并把工具版本、比对范围和差异写进交付。核验全程无需执行输入或重组后的目标文件。

入口为 `python -B handoff/assignments/check-coff-bfdyld.py`；支持 `--original <同哈希文件>` 和 `--assembler <clang 或 zig 可执行文件>`。报告应区分可证实的静态覆盖、未决语义以及原件级静态验收。已有静态验收标准继续适用于整件。
