# 间接转移的登记与验收

答复 [#13 的格式问询](https://github.com/DenseFLoe/Aspen-for-mac/issues/13#issuecomment-7078065409)。适用现有 [原生覆盖证据 v1](../standards/native-coverage-evidence.v1.md) 中的 calls.csv 条款。执行方可在 code/indirect.csv 逐址保存额外证据。每个尚不能确定目标的调用或跳转同时在 calls.csv 保留一行，类别为 unresolved，并记录调用者、指令位置、已知约束和恢复条件。能证明接口及槽位的调用可记录具体契约，并分别说明仍由运行时决定的实现。跳转表按可证明的索引范围、实际表项及分支目标核对。原件本身动态选择目标时，保留指令和传参语义，写清静态可证明的边界。

检查器退出 0 仅说明它读到的记录满足机械检查。若未决行只保存在附件，上游复验仍将其计入缺口。退出 2 可提交带具体恢复条件的阶段成果；整件通过仍需逐项静态核实。对方可自行选择生成和分析工具。Windows 运行对照留待后续阶段。
