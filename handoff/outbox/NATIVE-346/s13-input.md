# ppexec.dll 第十三号恢复依据

原件 SHA-256 `d93227b9a8f77c09fc1294834b6a4d87ba03a0697a680039fdce35cb1ce4549a`。从 S1 和 S5 的重组清单逐一比对 532 个范围的原件 SHA-256，跳过四段表数据后解出 12,498 条指令。该范围内 `0x14e06` 是 `0x12188` 唯一有直接实证的调用。其前置 `0x14df4` 把 `0x11b24` 放入第四入参，函数把值经 RDI 传给 RAX，满足该支路条件时由 `0x121c0` 经 Guard CF 槽 `0x15d00` 调用。原件中该槽的初始目标 `0x14c40` 为 `jmp rax`。未发现指向 `0x12188` 的导出、DIR64 重定位或另一个已核实代码引用。此证据可用于收窄该位置的本地回调记录。

`0x14c60` 是 Guard XFG 两个分派槽 `0x15d08` 和 `0x15d10` 的初始转发函数，两处原件 DIR64 重定位一致。三个 `0x20a80` 读取位置与 `0x1283c` 的原子交换均已定位，在这批指令中没有发现该交换例程的直接调用或地址引用。原件 `0x22148` 只有取址例程 `0x12450` 明确引用，且两个槽在磁盘均为零。仍需沿实际注册或调用机制补齐证据。
